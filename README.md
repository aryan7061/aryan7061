| Area               | Implementation                                         |
| :----------------- | :----------------------------------------------------- |
| **Frontend**       | React · TypeScript · Refine · Ant Design               |
| **Backend**        | NestJS · GraphQL · TypeORM                             |
| **Database**       | PostgreSQL · 7 relational entities                     |
| **Authentication** | JWT · bcrypt · role-based authorization                |
| **Performance**    | DataLoader batching · pagination · filtering · sorting |
| **Product**        | 17 routed pages · Kanban · analytics · Excel export    |
| **Additional**     | INR/USD conversion · record-level access control       |

### Architecture Highlights

* **GraphQL CRUD** with pagination, filtering, sorting and aggregates
* **DataLoader batching** to prevent N+1 queries
* **JWT authentication** with server-side authorization
* **Four roles** with record-level access control
* **Versioned PostgreSQL migrations**
* **Drag-and-drop Kanban board**
* **Analytics dashboards**
* **Excel data export**
